# animAItion ✦ Studio

An automated AI-driven social video animation studio built for TikTok (9:16), YouTube (16:9), and Instagram (1:1 / 4:5).

## Features
- **30+ Second Master Storyboards**: 5 to 6 sequential narrative chapters with dynamic phase progression.
- **Multiple Video Production Formats**:
  - Stickman / Cartoon Animations
  - Explainer Concept Mind-Maps
  - Demo / How-To Walkthroughs
  - Brand & Promo Metric Showcases
  - Live-Action vs. Animation Split Screens
  - UGC Creator Testimonials
  - Screencast Code Terminals
- **Procedural Entity Rendering**: Auto-detects real topics (Dogs, Cats, Cars, Crypto, Health, Tech) and renders high-definition physics animations alongside verified Lucide vector components.
- **Neural Voice Actors**: Features Google Neural AI voices (Puck, Charon, Kore, Fenrir, Aoede) with zero client API exposure.
- **1:1 Acoustic Karaoke Synchronization**: Spoken words highlight in TikTok-yellow at the exact millisecond they are uttered.
- **Client-Side Export**: High-framerate browser recording straight to `.webm`.

## Deployment on Vercel

1. Push this repository to GitHub.
2. Import project on [Vercel](https://vercel.com).
3. Set Environment Variable in Vercel Project Settings:
   - `GEMINI_API_KEY`: `your_gemini_api_key_here`
4. Deploy!

## Local Development
```bash
npm install
npm run dev
```
